# Librería de análisis y uso de Oracle (histórico)

Este documento describe una interfaz heredada y no el flujo canónico actual.
La ruta `dihiggs/` se refiere al subárbol fuente de este repositorio, no a un
ejecutable Oracle garantizado. Para el flujo vigente consulta el [README del
repositorio](../../README.md) y su [quickstart](../../docs/quickstart.md).

Oracle es llamado el programa generado con make dentro de `dihiggs/`, cabe destacar que una vez lo generes debes de modificar la ruta en `oracle.py` para asi llamarlo.
