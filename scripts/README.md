# scripts/: study and campaign scripts

Study, pilot and characterization helpers for the canonical v2 evaluators
(`run_*_pilot.py`, `jev_*`, `generate_golden_lambda1.py`,
`build_lambda1_characterization.sh`, ...). Each script documents its own usage
in its header.

The christopher fixed-lambda1 control campaign and its comparison scripts were
removed with the legacy lambda1 subsystem. Reproduce them with
`git checkout legacy-lambda1-final`.
